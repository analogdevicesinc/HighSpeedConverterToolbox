adi.QuadMxFE.Tx

The adi.QuadMxFE.Tx System object is a signal sink that can tranmsit complex data from the QuadMxFE.

tx = adi.QuadMxFE.Tx;
tx = adi.QuadMxFE.Tx('uri','ip:192.168.2.1');

AD9081 Datasheet

dev = adi.QuadMxFE.Tx

Example Usage

%% Configure device
tx = adi.QuadMxFE.Tx;
tx.uri = "ip:analog.local";
tx.DataSource = 'DMA';
tx.EnableCyclicBuffers = true;
tx.EnabledChannels = 1;

%% Generate tone
amplitude = 2^15; frequency = 0.12e6;
swv1 = dsp.SineWave(amplitude, frequency);
swv1.SamplesPerFrame = 2^14;
swv1.SampleRate = tx.SamplingRate;
y = swv1();

%% Send
tx(y);
